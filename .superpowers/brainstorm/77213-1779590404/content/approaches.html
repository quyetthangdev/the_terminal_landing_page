3 Hướng tiếp cận kiến trúc

Chọn cách tổ chức project phù hợp nhất

A

Vite + React SPA — Khuyến nghị ✓

Single page app thuần, dùng Vite để build nhanh. React Router cho scroll-to-section navigation. Three.js chạy trong Canvas riêng biệt ở hero. Tailwind + ShadcnUI cho toàn bộ UI. Deploy lên Vercel/Netlify bằng 1 lệnh.

Ưu điểm

  • Setup đơn giản, nhanh
  • Three.js tích hợp dễ
  • Build size nhỏ
  • Deploy dễ dàng

Nhược điểm

  • Không có SSR (SEO hơi kém)
  • First load chậm hơn Next.js một chút
B

Next.js App Router

Framework full-featured với SSR/SSG. SEO tốt hơn cho landing page nhà hàng. Three.js load với dynamic import (tránh SSR issue). Có thể thêm API routes cho form sau này.

Ưu điểm

  • SEO tốt (SSR/SSG)
  • Có thể thêm backend sau
  • Image optimization tích hợp

Nhược điểm

  • Setup phức tạp hơn
  • Three.js cần dynamic import riêng
  • Overkill cho landing page tĩnh
C

Vite + React Multi-page

Mỗi section (Menu, Reservation) là một route riêng. Cho phép lazy-load Three.js chỉ khi cần. Code splitting tự nhiên.

Ưu điểm

  • Code splitting tự nhiên
  • Mỗi page load nhanh hơn

Nhược điểm

  • Landing page bị chia nhỏ, mất trải nghiệm scroll liền mạch
  • Phức tạp hơn SPA không cần thiết
